# Datheon Machine Learning and Data Science Internship

This repository contains the public submission files for two Datheon tasks.

| Task | Project | Files and instructions |
| --- | --- | --- |
| 1 | Iris classification: Logistic Regression and Decision Tree | [Task 1](task_1_iris_classification/) |
| 2 | California housing regression: OLS, Ridge, and Lasso | [Task 2](task_2_housing_regression/) |

Each task folder contains its notebook, dataset, README, and required Python packages. Task 2 also includes exported figures and result tables. The task READMEs explain the methods, results, and limitations.

## Run a task

Open a terminal in the task folder and install its dependencies:

```bash
python -m pip install -r requirements.txt notebook
python -m notebook
```

Open the task notebook and run its cells from top to bottom. Keep the dataset beside the notebook. Use Python 3.11 or newer; the supplied analyses were executed with Python 3.12.
